# 2026-05-08 — docs / UX drift

## F7 — README + GET_STARTED have no `--agent` JSON envelope sample

- **Where:** `README.md`, `GET_STARTED.md`
- **Observed:** examples show `vegastack ask --agent --pack cloudflare "wrangler deploy"` but never show what stdout looks like.
- **Fix:** add one short redacted JSON sample under the agent-mode section in `GETTING_STARTED.md` (post-rename) showing `{ knowledge: [...], files: [...], citations: [...], match_reasons: [...] }`. First-time agent integrators need to see the envelope before they wire it up.
