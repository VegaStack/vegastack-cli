# v0.1 single-shot overrides to v1-plan.md

User decisions on 2026-04-28:

1. **Ship everything as v0.1.** This is the project's first public release. **No migration / backward-compat work.** Drop §6 entirely. The v0.2/v0.3/v1.0 sequencing in §1 §6 §7 collapses — everything in those sections is in scope for v0.1 EXCEPT what's explicitly deferred below.

2. **MCP server: Cloudflare Remote MCP only.** No stdio MCP wrapper. Use the official Cloudflare Agents SDK pattern documented at https://developers.cloudflare.com/agents/guides/remote-mcp-server/. Deploy to Cloudflare Workers in a separate folder `apps/mcp/` inside the CLI repo. Reachable from `https://mcp.vegastack.com/sse` (or similar). Drop all references to `vega mcp serve` (in-process).

3. **Public eval dashboard: Astro on Cloudflare Workers.** Build in `apps/dashboard/` (separate folder). User said "Astro 6.1.x" — **VERIFY the actual current stable** (likely 5.x as of April 2026; Astro v6 may be in beta or not exist). Use the `@astrojs/cloudflare` adapter. **Deploy to Cloudflare Workers, not Cloudflare Pages** — Workers static-assets binding (April 2025+ feature) is the modern path. Reachable from `https://evals.vegastack.com` (or similar).

4. **Modern UI.** User said "use front-end design plugin of Claude Code". **Web-search what's available** in April 2026 — likely candidates: anthropics/skills `frontend-design` skill, shadcn-ui Astro integration, Tailwind v4. Pick the most production-grade option and apply it. The dashboard should look like a real product, not a demo.

5. **Telemetry:** v0.1 ships the no-op `vega telemetry status|enable|disable|purge` stubs for forward compat. Actual PostHog integration deferred (no scope change from plan §7).

6. **Personas:** still empty in v0.1. Skip entirely.

7. **Beyond-Terraform surfaces:** still v0.4+. Skip entirely. Only schema-shaped placeholder dirs allowed.

8. **Versioning:** `@vegastack/cli` package.json version stays `0.1.0`. Bundle version in CalVer (`2026.04.28`). No semver acrobatics yet.

9. **Existing folder layout addition:**
   - `/Users/mk/projects/vegastack-cli/apps/mcp/` — Cloudflare Workers MCP server (NEW)
   - `/Users/mk/projects/vegastack-cli/apps/dashboard/` — Astro Cloudflare Workers eval dashboard (NEW)
   Both have their own `package.json` and `wrangler.toml`. They are NOT shipped via npm; they are deployed separately to Cloudflare.

10. **Web-search-first rule for every team:** Before installing any package, every team must `WebSearch` for the current version and changelog. Pin nothing from 2024 if a 2026 version exists. Especially:
    - Astro core + `@astrojs/cloudflare` adapter
    - Cloudflare Agents SDK (`agents` npm pkg)
    - `@modelcontextprotocol/sdk`
    - `wrangler` CLI
    - `@changesets/cli`
    - `proper-lockfile`
    - `cosign-installer` GH action
    - `actions/attest-build-provenance`
    - `vitest`

    - shadcn-ui Astro integration / Tailwind v4 / any other UI lib

   Prefer the latest *stable* (not RC, not beta) unless a beta is required for a documented feature.
