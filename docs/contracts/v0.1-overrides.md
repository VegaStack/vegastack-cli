# Current Release Notes

VegaStack is Registry-first. There is no public archive installer, no hidden
Terraform shortcut command, and no backward compatibility requirement for the
removed `install`, `refresh`, `tf`, or `terraform` command surfaces.

Project initialization:

- `vegastack init` creates committed `.vegastack/vegastack.yml`.
- There is no project lock file; volatile detection cache lives under `~/.vegastack/cache/`.
- Registry pack data is cached under the user's VegaStack config directory.

Command model:

- `vegastack ask` builds grounded agent evidence.
- `vegastack search` performs exact local Registry search.
- `vegastack registry update` refreshes selected Registry entries.
- Terraform provider-specific routing uses `vegastack ask --entry terraform
  --tf-provider <provider>`.
