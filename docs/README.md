This is the engineering record for the v0.1 release: every research input, every contract, every status report from the execute teams. Treat it as the project's audit trail. New contributors should read in numerical order.

## Reading order for a new contributor

1. `planning/01-initial-eval-baseline-2026-04-28.md` — understand the problem we set out to solve.
2. `planning/07-v1-plan-synthesis.md` §1 (executive summary) and §2 (architecture).
