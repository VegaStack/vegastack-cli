## Bugs surfaced by full E2E (already fixed in working tree, included in release)

1. **Critical:** `vegastack registry install --all` rejected every Registry pack with `ArtifactCorrupt: unexpected file in registry archive: ARTIFACTS.json`. Fixed in `src/lib/registry.ts:562` by seeding the allowlist with the index file. Pinned by 4-case regression test.
2. **High:** `vegastack ask` and `vegastack search` (without `--pack`/`--all`) always failed with "no Registry packs are selected" because commander's empty-`[]` default for `collect` short-circuited the project-config resolver. Fixed in `src/cli.ts:305,364` and `src/commands/_shared.ts:39`. Pinned by `tests/commands/ask-search-empty-pack.test.ts`.

Both bugs are pre-existing — present in 0.1.13-next.2 as currently published, but uncovered only when the `--all` install flow hit a real Registry archive that includes `ARTIFACTS.json`. They would have hit every user on first install.
